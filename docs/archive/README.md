# Archived pre-rewrite documentation

Everything under `docs/archive/` describes the **superseded** tensor/ONNX
architecture of hologram-ai (AiGraph, hologram-substrate tensor execution,
ORT conformance, browser tensor app). It is retained for historical reference
only and is **not normative**.

The current architecture is defined by:

- `docs/rewrite-plan.md` — the rewrite plan and ownership boundaries
- `docs/architecture.md` — current system architecture
- `docs/adrs/` — current Architecture Decision Records (0001+)
